Open LCORL_splicing_animation.html locally. It needs no server or internet.
Choose an isoform and SNP, press Play, or drag the timeline. Save SVG exports the current vector frame.
The genomic DNA stays intact. The pre-mRNA exon blocks move together as introns disappear.
Each tracked site is retained in its exon and mapped to mature mRNA, CDS and protein.
mRNA includes UTRs; CDS coordinates do not. All coordinates are 1-based.
On the negative strand, exon 1 is at the high-coordinate end and RNA alleles are complemented.
Exon numbering is transcript-specific. Codons crossing splice junctions retain all three mapped genomic positions in the TSV.
Exact exon coordinates are from the supplied GFF. Do not use the schematic widths as physical genomic distances.
Reference splicing only: this is not evidence that any variant alters splicing.
The build uses only the Python standard library and leaves the script, input subset, hashes, tables and logs here.
